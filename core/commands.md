# ⚡ Comandos de Flutter Payments Agent Skill (`flutter-payments-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$payments` | Bootstrap | Inicializa la skill de pasarelas de pago para Flutter. |
| `$payments:audit` | Auditoría | Audita pasarelas In-App Purchases, Stripe, PayPal y Webhooks. |
| `$payments:iap` | Integración | Configuración de in_app_purchase / RevenueCat. |
| `$learnskill flutter-payments-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `flutter-payments-agent-skill` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
